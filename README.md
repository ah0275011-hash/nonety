# Birthday Website

## التشغيل
1. افتحي فولدر المشروع في VS Code.
2. افتحي `index.html` في المتصفح (يفضل باستخدام إضافة Live Server).
3. كلمة السر الافتراضية للتجربة: `0505`.

## تخصيص كلمة السر
افتحي `js/script.js` وغيّري قيمة `SECRET_PASSWORD`.

## إضافة الموسيقى
ضعي ملف MP3 داخل `assets/music/` وسمّيه `background.mp3`.

ملاحظة: كلمة السر هنا واجهة بسيطة للتجربة وليست حماية أمنية حقيقية؛ لأن HTML وJavaScript يمكن فحصهما من المتصفح.
